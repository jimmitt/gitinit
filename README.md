# About

This tutorial is a translation of a fantastic Mercurial website into an equivalent Git tutorial.  The original site by [Joel Spolsky](https://www.joelonsoftware.com/) was hginit.com.  The original hginit.com is no longer available but you can read an archived version of the tutorial at <https://hginit.github.io>

I'm a big fan of Joel's writing and version control really started making sense after I went through hginit.com.  I've taught electrical and computer engineering at the college level and have seen many students struggle with Git.  In my opinion, Git is much less intuitive than Mercurial.  My hope is that converting hginit into gitinit will help future engineers understand version control with Git in the same way the original site helped me with Mercurial.

-James
