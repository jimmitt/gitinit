# GitInit

GitInit is a friendly, six-part introduction to Git. It teaches the concepts
behind everyday commands: local snapshots, the staging area, branches, remotes,
collaboration, recovery, merging, tags, and repository architecture.

The project began as a Git-focused reworking of Joel Spolsky's influential
Mercurial tutorial, Hg Init. The current text has been rewritten around Git's
own data model and modern command set rather than translating commands one for
one. The archived original is available at <https://hginit.github.io>.

## Chapters

1. Think in Git
2. Git from the Ground Up
3. Working with a Team
4. Fixing Mistakes
5. Branches and Merging
6. Repository Architecture
